# Форк Nimbalyst 0.79.1+m4xp1.2

База upstream v0.79.1 (2535d61ca9060a43c50335501380f4c1664047aa), Windows x64. Предыдущие теги сохраняются.

## Изменения

- Встроенный редактор CONTENT карточки скрывает повторные breadcrumb/toolbar и metadata, сохраняет общий файловый редактор и его ошибки записи.
- Контекстное меню пустого пространства файлового дерева работает с корнем проекта, сохраняя ограничения операций над корнем.
- BM25/recall отделяют конечную пунктуацию от слов; технические идентификаторы с внутренними точками/слешами сохраняются. Миграция словаря v3 меняет sparse terms, сохраняя vectors и без embedding API.
- Неизменённый Rebuild не переписывает chunks. Index size показывает выделенные SQLite-страницы; временные WAL/SHM не считаются индексированным содержимым.
- Additional text sources сохраняет Include/Exclude по blur или закрытию страницы, последовательно применяет быстрые изменения, сохраняет пустые списки. Preview/Apply и их backend API удалены. Убраны предустановленные исключения: пользователь задаёт их сам. Раздел без внешней рамки, с обычным заголовком и нижним divider.
- Файлы/каталоги/globs остаются относительными workspace; пересечения дедуплицируются, встроенная классификация сохраняется. Литералы сохраняют введённый вид; каталог расширяется в dir/** при сопоставлении, без навязанного *.md.
- Дополнительные источники читают произвольный UTF-8 текст, в том числе JSON/YAML/код/файлы без расширения. Содержимое с NUL или некорректным UTF-8 пропускается. Только .md разбираются как Markdown; для прочих текстов сохраняются leading --- и буквальные заголовки. Бинарные форматы не разбираются.
- Встроенные файловые источники остаются Markdown: docs, design, nimbalyst-local/plans, voice-memory, CLAUDE.md/AGENTS.md, .claude/rules, включая соответствующие вложенные пути. Personal harness memory и virtual trackers/sessions сохранены.
- Для OpenAI text-embedding-3-small dense candidates фильтруются по raw cosine >=0.35 до RRF. Keyword matches остаются допустимыми независимо от cosine. Порог — начальная инженерная настройка по малому fixture, не универсальная гарантия релевантности. Для других моделей исходная политика сохранена; EngineConfig.minDenseCosine позволяет задать иной порог. RRF score в UI явно обозначен как rank, не вероятность. Изменение применяется к общему движку UI/MCP/context и при открытии сохранённой БД.

## Версия и ограничения

About/app: 0.79.1+m4xp1.2. Windows FileVersion 0.79.1.2, numeric revision 2; SemVer build metadata не меняет сравнение базовой версии. Updater использует официальный upstream с autoDownload=false и autoInstallOnAppQuit=false. Индикаторы лимитов остаются upstream.

Сохранён исходный порядок embed-before-save: при отказе провайдера новые тексты могут не сохраниться, проход может быть partial. Retry/backoff, кэш запросов, смена модели и дополнительные binary parsers не добавлены. При OpenAI новые/изменённые тексты и поисковый запрос используют действующий API. Refresh только читает статус, Rebuild переиспользует неизменные vectors. Отсутствие релевантной выдачи допустимо; порог требует проверки на реальных запросах пользователя.
