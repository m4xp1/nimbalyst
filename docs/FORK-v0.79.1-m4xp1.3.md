# Форк Nimbalyst 0.79.1+m4xp1.3

База upstream v0.79.1 (2535d61ca9060a43c50335501380f4c1664047aa), Windows x64. Старые выпуски сохраняются.

## Изменения этой ревизии

- Additional text sources: два абзаца с форматами и встроенными источниками; убран разделитель перед Memory search. UTF-8 текст произвольного расширения обрабатывается как текст; только .md использует Markdown parsing, binary пропускается.
- Отключение Also index AI sessions очищает все виртуальные refType=session из Memory, включая устаревшие записи. Сериализация для каждого workspace ждёт отправленную запись, отменяет устаревший backfill; запуск движка согласовывает сохранённую БД с настройкой. Файлы, trackers и основные AI-сессии сохраняются. Ошибки показываются в настройках.
- Semantic: удалён введённый форком порог 0.35 и его конфигурация. Восстановлены ближайшие upstream-кандидаты и RRF; слабые и посторонние результаты могут присутствовать. Сохраняются raw cosine и пояснение, что RRF score — значение ранжирования, а не уверенность.
- Keyword и recall: официальный JavaScript Russian Snowball 3.1.1, BSD-3-Clause. Из сохранённых частот строится дополнительная BM25-проекция в памяти. Только целиком русские буквенные токены получают основу; пути, идентификаторы, расширения, цифры и смешанные токены остаются точными. В keyword-ветви точные совпадения сохраняют прежние оценки и порядок, затем идут уникальные stem-only результаты. Веса RRF, лимиты кандидатов и число fusion-ветвей не меняются. Search results могут содержать keywordMatch: exact или stem; sparse остаётся keyword-сигналом. Итоговый hybrid-порядок учитывает semantic.
- Векторы, исходные тексты и схема БД не меняются, новая проекция доступна старому индексу без повторного embedding сохранённых текстов. Runtime, исходный JS и BSD-лицензия Snowball поставляются в resources/legal/snowball-russian-3.1.1.

## Версия и ограничения

About/app: 0.79.1+m4xp1.3; Windows FileVersion 0.79.1.3; buildNumber 3. SemVer build metadata не изменяет сравнение базовых версий. Updater: официальный upstream, autoDownload=false и autoInstallOnAppQuit=false. Индикаторы лимитов остаются upstream.

Стемминг не является словарной лемматизацией или подбором синонимов: возможны ложные объединения (вина/вино) и пропуски (орган/органами). Точные совпадения имеют приоритет только в keyword-ветви. Semantic retrieval не гарантирует нахождение нужного факта на первой позиции; новый порог не подбирался.

Сохраняется embed-before-save: отказ провайдера может оставить новые тексты несохранёнными и индекс partial. Retry/backoff, кэш запросов, смена модели, словари и binary parsers не добавлены. Refresh читает статус без сканирования/API; Rebuild переиспользует неизменные embeddings. Новые/изменённые тексты и поисковые запросы при OpenAI используют действующие настройки API.
