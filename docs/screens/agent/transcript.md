# Session transcript

Select text in the transcript or a Markdown document and choose **Add to chat** to attach an annotation to the active session draft. Select its marker to edit the comment. The composer list opens the original selection when it can be found. Save an empty comment to remove the annotation.

While a Codex app-server turn is running, **Queue** sends the draft after the current turn, **Send now** passes a follow-up to that turn, and **Stop** interrupts it. Use **Queue** to send file attachments.
